快速开始
====================================================================

【Windows 用户】
1. 双击运行：flash.bat
2. 根据提示输入串口号（如 COM3）
3. 等待烧录完成

【Linux/Mac 用户】
1. 打开终端，进入此目录
2. 运行：./flash.sh /dev/ttyUSB0 460800
3. 等待烧录完成

【手动烧录】
参见 "烧录说明.txt" 文件

====================================================================
文件说明
====================================================================

【固件文件】（5个必需文件）
  - bootloader.bin        (16 KB)   - 引导加载程序
  - partition-table.bin   (3 KB)    - 分区表
  - ota_data_initial.bin  (8 KB)    - OTA状态
  - xiaozhi.bin           (3.8 MB)  - 主应用程序 ⭐
  - generated_assets.bin  (266 KB)  - 资源文件

【烧录工具】
  - flash.sh              - Linux/Mac 烧录脚本
  - flash.bat             - Windows 烧录脚本
  - flash_project_args    - esptool 参数文件
  - flasher_args.json     - JSON 格式配置

【文档】
  - 烧录说明.txt          - 详细的烧录指南和故障排查
  - README.txt            - 本文件

====================================================================
重要配置
====================================================================

Flash 配置：
  - 模式：DIO (不是 QIO！)
  - 大小：16 MB
  - 频率：80 MHz

硬件配置（已从原理图确认）：
  - I2C：SDA=GPIO5, SCL=GPIO4
  - ES8311 地址：0x30 (或 0x18)
  - ES7210 地址：0x40 ✅

分区配置（方案3）：
  - 应用分区：5 MB (当前使用 3.8 MB，剩余 23%)
  - 资源分区：5.625 MB

====================================================================
验证烧录成功
====================================================================

串口监控（115200 波特率）应看到：

✅ I2C 扫描结果：
   0x18 或 0x30 (ES8311)
   0x40 (ES7210)

✅ 初始化成功：
   ES8311: Codec initialized successfully
   ES7210: Codec initialized successfully

✅ 蓝牙广播：
   手机可搜索到 "ESP32-PLAUD"

====================================================================
常见问题
====================================================================

Q: 烧录失败 "Failed to connect"
A: 按住 Boot 键，插入 USB，然后松开

Q: 设备不断重启
A: 检查 Flash 模式是否为 DIO（不是 QIO）

Q: I2C 扫描为空
A: 硬件问题，检查芯片供电和焊接

详细故障排查请参见 "烧录说明.txt"
