更新方式
====================================================================

【方式 1：快速更新（推荐）】
如果之前已经烧录过 v1 或 v2，只需要更新 xiaozhi.bin：

Linux/Mac:
python3 -m esptool --chip esp32s3 -p /dev/ttyUSB0 -b 460800 \
  --before default_reset --after hard_reset write_flash \
  --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x20000 xiaozhi.bin

Windows:
python -m esptool --chip esp32s3 -p COM3 -b 460800 ^
  --before default_reset --after hard_reset write_flash ^
  --flash_mode dio --flash_size 16MB --flash_freq 80m ^
  0x20000 xiaozhi.bin

⏱️ 烧录时间：约 20 秒

====================================================================

【方式 2：完整烧录（首次或保险）】
如果是第一次烧录，或想保险起见，烧录所有 5 个文件：

Linux/Mac:
python3 -m esptool --chip esp32s3 -p /dev/ttyUSB0 -b 460800 \
  --before default_reset --after hard_reset write_flash \
  --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x0 bootloader.bin \
  0x8000 partition-table.bin \
  0xd000 ota_data_initial.bin \
  0x20000 xiaozhi.bin \
  0xa20000 generated_assets.bin

Windows:
python -m esptool --chip esp32s3 -p COM3 -b 460800 ^
  --before default_reset --after hard_reset write_flash ^
  --flash_mode dio --flash_size 16MB --flash_freq 80m ^
  0x0 bootloader.bin ^
  0x8000 partition-table.bin ^
  0xd000 ota_data_initial.bin ^
  0x20000 xiaozhi.bin ^
  0xa20000 generated_assets.bin

⏱️ 烧录时间：约 30-40 秒

====================================================================
故障排查
====================================================================

Q: 烧录后仍然崩溃
A: 
   1. 确认使用了正确的固件（v3.0）
   2. 检查烧录地址是否正确（0x20000）
   3. 提供完整串口日志

Q: ES8311 或 ES7210 初始化失败
A: 
   1. v3.0 允许单个设备失败，不会崩溃
   2. 检查硬件：芯片是否焊接、电源是否正常
   3. 查看日志中的详细错误信息

Q: 音频没有声音
A: 
   1. 确认 "音频输出: ✅ 正常" 显示在日志中
   2. 检查功放 NS4150B 是否工作
   3. 检查扬声器连接
