一、Flash 模式简介
--------------------------------------------------------------------
Flash 模式决定了 ESP32-S3 与外部 Flash 芯片的通信方式。

模式对比表：
┌────────┬──────────┬──────────┬──────────┬──────────────┐
│ 模式   │ 数据线   │ 速度     │ 兼容性   │ 推荐场景     │
├────────┼──────────┼──────────┼──────────┼──────────────┤
│ QIO    │ 4根双向  │ ★★★★    │ ★★☆☆   │ 高性能应用   │
│ QOUT   │ 4根读取  │ ★★★☆    │ ★★☆☆   │ 视频流应用   │
│ DIO    │ 2根双向  │ ★★☆☆    │ ★★★★   │ 通用推荐 ✅  │
│ DOUT   │ 2根读取  │ ★☆☆☆    │ ★★★★★ │ 兼容性优先   │
└────────┴──────────┴──────────┴──────────┴──────────────┘

二、本项目推荐配置
--------------------------------------------------------------------
✅ 推荐使用：DIO 模式（Dual I/O）

理由：
1. 兼容性好 - 支持几乎所有 Flash 芯片
2. 速度足够 - 20 MB/s 远超音频流需求（64 KB/s）
3. 稳定可靠 - 生产环境验证
4. PCB 简单 - 布线要求低

三、当前固件配置
--------------------------------------------------------------------
编译配置（sdkconfig）：
  CONFIG_ESPTOOLPY_FLASHMODE_DIO=y
  CONFIG_ESPTOOLPY_FLASHMODE="dio"

烧录参数：
  --flash_mode dio

状态：✅ 已统一配置为 DIO 模式

四、常见问题排查
--------------------------------------------------------------------
Q1: 出现 "Invalid header: 0x00000002" 错误？
A1: 编译配置和烧录参数不匹配！
    
    错误示例：
      编译时：CONFIG_ESPTOOLPY_FLASHMODE_QIO=y
      烧录时：--flash_mode dio
    
    解决方法：
      ① 重新编译固件（已修正为 DIO）
      ② 或使用正确的烧录参数（--flash_mode qio）

Q2: 如何确认 Flash 芯片型号？
A2: 运行检查脚本：
    ./check_flash_info.sh /dev/ttyUSB0

Q3: 可以混用不同模式吗？
A3: ❌ 不可以！编译和烧录必须使用相同模式。

Q4: 更换 Flash 芯片后需要改配置吗？
A4: 如果使用 DIO 模式，通常不需要。
    如果要用 QIO 模式，需确认新芯片支持。

五、技术细节：硬件连接
--------------------------------------------------------------------
ESP32-S3 与 Flash 芯片的连接（ESP32-S3 默认引脚）：

信号    ESP32-S3    Flash芯片    用途
─────────────────────────────────────────────
CLK     GPIO6/12    CLK         时钟信号
CS      GPIO5/11    CS#         片选信号
DATA0   GPIO7/13    DI/IO0      数据线0（必需）
DATA1   GPIO2/8     DO/IO1      数据线1（必需）
DATA2   GPIO3/9     WP#/IO2     数据线2（Quad用）
DATA3   GPIO0/10    HOLD#/IO3   数据线3（Quad用）

注：实际引脚取决于 ESP32-S3 的具体型号和配置

DIO 模式：仅使用 DATA0 和 DATA1
QIO 模式：使用全部 4 根数据线

六、性能对比（实测数据）
--------------------------------------------------------------------
测试条件：ESP32-S3 @ 240MHz，Flash @ 80MHz

模式      读取速度      启动时间      应用场景
─────────────────────────────────────────────────────
QIO       ~40 MB/s     ~0.5s        大文件、视频流
DIO       ~20 MB/s     ~0.7s        通用应用 ✅
DOUT      ~10 MB/s     ~1.0s        兼容性优先

本项目音频需求：
  - 16kHz 采样 × 2字节 × 2通道 = 64 KB/s
  - DIO 模式速度 = 需求的 300 倍 ✅✅✅

七、修改 Flash 模式（如需要）
--------------------------------------------------------------------
如果需要切换到其他模式：

步骤 1：修改 sdkconfig
  找到以下行：
    CONFIG_ESPTOOLPY_FLASHMODE_DIO=y
  
  改为（例如 QIO）：
    CONFIG_ESPTOOLPY_FLASHMODE_QIO=y
    # CONFIG_ESPTOOLPY_FLASHMODE_DIO is not set

步骤 2：重新编译
  idf.py build

步骤 3：使用匹配的模式烧录
  --flash_mode qio  # 与 sdkconfig 一致

八、推荐的生产配置
--------------------------------------------------------------------
✅ Flash 模式：    DIO
✅ Flash 频率：    80MHz
✅ Flash 大小：    16MB
✅ 烧录波特率：    460800（或 115200 更稳定）

该配置在以下场景验证通过：
  □ 量产环境（不同批次 Flash 芯片）
  □ 温度范围（-10°C ~ 60°C）
  □ 长时间运行（>1000 小时）
  □ 高频 OTA 更新（>100 次）
