快速开始
====================================================================

【Windows 用户】
1. 双击运行：flash.bat
2. 输入串口号（如 COM3，默认）
3. 等待烧录完成

【Linux/Mac 用户】
1. 打开终端，进入此目录
2. 运行：chmod +x flash.sh
3. 运行：./flash.sh /dev/ttyUSB0
4. 等待烧录完成

【手动烧录】
详见 "烧录说明.txt"

重要配置
====================================================================

Flash 配置：
  模式：DIO (不是 QIO！)
  大小：16 MB
  频率：80 MHz

硬件状态：
  ✅ ES8311 (DAC/音频输出) - 地址 0x18
  ⏸️  ES7210 (ADC/麦克风) - 未焊接

当前可测试功能：
  ✅ 设备正常启动（不会崩溃）
  ✅ 蓝牙广播（ESP32-PLAUD）
  ✅ LCD 显示屏
  ✅ 音频输出（ES8311）
  ✅ 按键功能
  ❌ 麦克风录音（需要 ES7210）

====================================================================

40: 40 -- -- -- -- -- -- -- -- -- -- -- -- -- -- --  ← ES7210 ✅

I (xxx) ES7210: Codec initialized successfully  ✅
I (xxx) DualI2sAudioCodec 完全初始化（输入+输出）

====================================================================
故障排查
====================================================================

Q: 烧录失败
A: 按住 Boot 键，然后插入 USB

Q: 设备不断重启
A: 检查 Flash 模式是否为 DIO

Q: I2C 扫描为空
A: 检查芯片供电和焊接

详细故障排查：见 "烧录说明.txt"
